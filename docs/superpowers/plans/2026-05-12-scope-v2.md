## Phase 1 — graph_builder (pure function)

### Task 1.1: Write tests for graph_builder

**Files:**
- Create: `/Users/jakefassora/projects/scope/tests/test_graph_builder.py`

- [ ] **Step 1:** Write failing tests covering:
  - Empty inputs → just a `home` node, no edges.
  - One config file → one config node, one edge from `home`.
  - One repo + one worktree (with resolvable parent) → repo as child of home, worktree as dashed child of repo.
  - One worktree with no resolvable parent → attached to `home`.
  - One process whose cwd matches a repo → process node with `attached_to_id` set to that repo's id, edge with `style: "process"`.
  - Process whose cwd matches no node → `attached_to_id: null`, edge from `home`.
  - HIGH finding targeting a config file → that node's `severity` is `"HIGH"`.
  - MED finding on same node as a HIGH finding → severity stays `"HIGH"` (highest wins).

Each test calls `build_graph(claude_files, project_md, repos, worktrees, processes, findings, home_path)`.

- [ ] **Step 2:** Run pytest. Expect failure (module missing).

### Task 1.2: Implement graph_builder

**Files:**
- Create: `/Users/jakefassora/projects/scope/scope/graph_builder.py`

- [ ] **Step 1:** Implement `build_graph(...)`. Pure function. No imports beyond `typing` and stdlib. Steps inside:
  1. Start with a single `home` node.
  2. For each entry in `claude_files + project_md`, create a `config` node and an edge from `home` (or from a repo node if the file path lives inside that repo).
  3. For each repo in `repos`, create a `repo` node and an edge from `home`.
  4. For each worktree in `worktrees`, try to find a parent repo by matching prefixes of its path against repo paths. If found, make it a `worktree` node with `parent_repo_id` + dashed edge to that repo. Otherwise edge from `home`.
  5. For each process in `processes`, create a `process` node. If its `cwd` matches a repo path, set `attached_to_id` to that repo's id AND set the repo node's `has_process: true`. Otherwise `attached_to_id: null` and edge from `home`.
  6. Build a `path → highest_severity` map from `findings` (order: HIGH > MED > LOW). For each node that has a `path` field, set `severity` from the map (or `null`).
  7. Return `{ "nodes": [...], "edges": [...] }`.

- [ ] **Step 2:** Run pytest. Expect all tests pass.

- [ ] **Step 2:** Add route after `/api/insights`:
```python
@app.get("/api/graph")
def api_graph():
    claude_files = scan_claude_dir(HOME / ".claude")
    project_md = find_claude_md_files(HOME / "projects")
    repos = find_repos(HOME / "projects")
    worktrees = find_repos(HOME / ".claude" / "worktrees")
    processes = find_claude_processes()
    home_is_repo = (HOME / ".git").is_dir()
    findings = evaluate_all(
        config_files=claude_files + project_md,
        repos=repos,
        worktrees=worktrees,
        home_is_git_repo=home_is_repo,
    )
    return jsonify(build_graph(
        claude_files=claude_files,
        project_md=project_md,
        repos=repos,
        worktrees=worktrees,
        processes=processes,
        findings=findings,
        home_path=str(HOME),
    ))
```
