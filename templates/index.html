Start a new Claude Code project

  1. Create the folder and init git

    mkdir -p ~/projects/my-new-project
cd ~/projects/my-new-project
git init -b main

  2. Open Claude Code in the folder

    claude

    Then either seed it yourself or have Claude scaffold the whole thing.

  3. Seed a small CLAUDE.md (keep it under 8 KB)

    Paste this prompt:

    Create a CLAUDE.md for this project. Cover: goal, stack, file layout,
coding style, and any "never do" rules. Keep it under 200 lines.

  4. Or: have Claude do the whole scaffold in one shot

    Paste this prompt (no terminal commands needed — Claude runs them):

    Scaffold a new project at ~/projects/my-new-project. Stack: [Python / Node / Go / etc].
Goal: [one sentence]. Init git on branch main, write a short CLAUDE.md and README.md,
make the first commit "chore: scaffold". Stop and show me the tree before doing anything else.

  5. Make it visible to scope

    • Folder must live under ~/projects/ to appear in the Git State tab.
    • Keep CLAUDE.md small — large auto-load files trigger an Insights warning.
    • Add a GitHub remote and push so the Git State tab can show ↑ahead / ↓behind: 
      gh repo create my-new-project --private --source=. --remote=origin --push
