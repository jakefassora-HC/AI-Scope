Cards. One card per project. Each phase expands to show the actual .md/.html plan files. Click any file to read it. Highest information density; most usable day-to-day.
Zoomable circle packing. Bubbles sized by content. Click to zoom in: project → plans group → phase → individual plan files. Click a plan file leaf to read it.
Zoomable sunburst. Radial hierarchy — center = root, rings = depth. Click a sector to refocus. Phase status drives color.
Sankey flow. .claude (global config) → each project → status buckets. Every project shows up — width = phase count. Projects with no .planning/ still flow through "no phases" so you see your full portfolio.
